🎮 Retro Tanks JSRetro Tanks JS — это динамичный 2D-шутер для двух игроков, созданный на чистом JavaScript. Проект сочетает в себе классический геймплей «танчиков» с современным подходом к архитектуре кода.🚀 Особенности проектаNo-Server Ready: Благодаря оптимизации загрузки через defer, игра запускается обычным двойным кликом по index.html (идеально для демонстрации на любых ПК).Модульная архитектура: Логика разделена на конфиги, рендеринг и игровой движок для удобства масштабирования.CRT Retro Aesthetic: Оформление в стиле старых мониторов для глубокого погружения.Система коллизий: Реализована обработка препятствий (бетон, вода, кирпич) и прострелов.🕹️ УправлениеИгра предназначена для локального мультиплеера (два игрока за одной клавиатурой).ДействиеИгрок 1 (Зеленый)Игрок 2 (Желтый)ДвижениеW, A, S, DСтрелки ↑, ←, ↓, →ВыстрелПробелEnterЦель: уничтожить танк противника 5 раз.🗺️ Игровые зоныВ игре реализовано три тактических сценария:Эхо Прошлого — классическая симметричная карта.Коридор Возмездия — узкие проходы и водные преграды.Стальной Перекресток — открытая зона с бетонными укреплениями.🛠️ Технический стекFrontend: HTML5, CSS3, JavaScript (ES6+).Graphics: Динамическая генерация SVG-объектов.Deployment: GitHub Pages.📁 Структура файловPlaintextproject/
