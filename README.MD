# Retro Tanks JS

**Retro Tanks JS** — это динамичный 2D-шутер для двух игроков, созданный на чистом JavaScript. Проект сочетает в себе классический геймплей «танчиков» с современным подходом к архитектуре кода.

---

## Особенности проекта
* **No-Server Ready:** Благодаря оптимизации загрузки через атрибут `defer`, игра запускается обычным двойным кликом по `index.html` (идеально для демонстрации на учебных ПК).
* **Модульная архитектура:** Логика разделена на конфиги, рендеринг и игровой движок для удобства поддержки.
* **CRT Retro Aesthetic:** Оформление в стиле старых мониторов для глубокого погружения.
* **Система коллизий:** Реализована обработка препятствий (бетон, вода, кирпич) и механика стрельбы.

---

## Управление

Игра предназначена для локального мультиплеера (два игрока за одной клавиатурой).

| Действие | Игрок 1 (Зеленый) | Игрок 2 (Желтый) |
| :--- | :--- | :--- |
| **Движение** | `W`, `A`, `S`, `D` | Стрелки `↑`, `←`, `↓`, `→` |
| **Выстрел** | `Пробел` (Space) | `Enter` |

> **Цель:** Уничтожить танк противника 5 раз для победы в раунде.

---

## Технический стек
* **Frontend:** HTML5, CSS3, JavaScript (ES6+).
* **Graphics:** Динамическая генерация SVG-объектов для танков.
* **Architecture:** Собственный движок обработки коллизий и состояний.
