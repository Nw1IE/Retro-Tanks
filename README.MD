# Retro Tanks JS

**Retro Tanks JS** — это динамичный 2D-шутер для двух игроков, созданный на чистом JavaScript. Проект сочетает в себе классический геймплей «танчиков» с современным подходом к архитектуре кода.

---

## Особенности проекта
* **Модульная архитектура:** Логика разделена на конфиги, рендеринг.
* **CRT Retro Aesthetic:** Оформление в стиле старых мониторов для глубокого погружения.
* **Система коллизий:** Реализована обработка препятствий (бетон, вода, кирпич) и механика стрельбы.

---

## Управление
| Действие | Игрок 1 (Зеленый) | Игрок 2 (Желтый) |
| :--- | :--- | :--- |
| **Движение** | `W`, `A`, `S`, `D` | Стрелки `↑`, `←`, `↓`, `→` |
| **Выстрел** | `Пробел` (Space) | `Enter` |

---

## Технический стек
* **Frontend:** HTML5, CSS3, JavaScript (ES6+).
* **Graphics:** Динамическая генерация SVG-объектов для танков.

---

## Структура проекта
```
project/
```
